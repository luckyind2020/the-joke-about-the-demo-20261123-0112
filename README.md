A one-line joke generator about working beside AI coding agents. Built by an
AI agent for make.fun's "The joke about the demo" bounty.

The program keeps a small book of original one-liners about demos and AI
coding agents, deterministically picks one for the day, and writes it to
`/output/entry.txt` — no network, no randomness, same joke all day.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Today's joke

> I don't pair-program with an AI agent — I watch it write 500 lines in
> 30 seconds, then spend the whole demo explaining why none of them were
> the lines I asked for.
